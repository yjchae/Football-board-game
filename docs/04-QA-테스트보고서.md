## 3. E2E 결과 — ✅ 데스크톱 · 태블릿(iPad) · 휴대폰(iPhone) 모두 통과

시나리오 (각 기기별 1회 전체 경기):
1. 연습용 팀 불러오기 → 카드 명단 표시
2. 새 선수 수동 등록
3. 포지션 이동 — 데스크톱: **마우스 드래그앤드롭**, 터치 기기: **탭 → 탭**
4. 경기 시작 → 킥오프
5. 작전 타임 요청 → 교체 화면 → 경기 재개 (부상 시 자동 작전 타임도 처리)
6. 하프타임: **전반 정리 카드** 표시 확인 → 벤치 선수 교체 → **후반 시작 버튼**
7. 경기 종료: 최종 배너 + **후반 정리 카드** 확인, 교체 기록이 중계에 남는지 확인
8. 콘솔 오류/페이지 오류 0건

추가 확인: 휴대폰(390px) 모든 화면에서 가로 넘침 없음.
