## 1. 포지션 변경 오류 (R1~R14)
| # | 조건 | 위치 | 수정 |
|---|---|---|---|
| R1 | GK 슬롯 선수를 필드 쪽 빈 잔디로, 또는 필드 선수를 y>78로 끈다 → clamp로 조용히 안 움직임 | positions.ts movePosition/clampPoint | clamp 결과가 사실상 제자리(3% 미만)면 이동 취소 + 에러 "골키퍼는 골문 근처에서만 움직여요" / "수비 라인 뒤쪽까지만 갈 수 있어요" |

| R11 | GK 2장 이상 사진 팀: 두 번째 GK가 필드 슬롯(0.5배) | 〃 | OVR 최고 1명만 gk, 나머지는 벤치(필드 10명 미만일 때만 필드에 사용) |

## 2. 포메이션 추가
- 프리셋 추가(기존 4개 뒤에 붙임, 순서 변경 금지): 5-3-2, 3-4-3, 4-1-4-1, 4-5-1.
- 직접 입력: 숫자 3~5개, 각 1~6, 합계 10. 맨 앞 DF, 맨 뒤 FW, 사이는 MF 줄. DF y=72, FW y=18, MF 줄은 균등. 라벨은 `labelFor`.
- `Lineup.formationId`는 규칙 문자열 자체("4-1-4-1"). `getFormation(id)`: FORMATIONS → 파싱 → 실패 시 FORMATIONS[0]. 슬롯 id: gk, df1.., 중간줄 `m{줄}_{순번}`, fw1... 기존 4종 슬롯 id/좌표 변경 금지(저장 호환).
- 전역 `customFormations: string[]`(최대 8, 오래된 것부터 삭제). merge에 Array.isArray 가드.
- 공용 `FormationPicker`를 TeamsScreen·TacticsPanel이 같이 사용. 안내 "포메이션을 누르면 옮긴 위치는 기본 위치로 돌아가요".
- 경기 중 변경은 기존처럼 킥오프 전·작전타임·하프타임만.

## 3. 이적시장
- `MAX_SQUAD = 25` (`domain/market.ts`). 스토어 addPlayer/addPlayers에서 남은 자리만큼만 추가. 화면에서도 선제 차단: 랜덤 뽑기(남은 자리보다 큰 인원 옵션 비활성, 0이면 안내), 팀 스캔(체크 제한), 수동 추가 카드 비활성.
- 이미 25명 초과 팀: 삭제 없음, 추가만 막고 "26/25" 표시, 교환은 허용.
- 랜덤 뽑기 on/off: `AiSettings.randomDraft`(기본 true), 설정 화면 "선수 영입" 패널 Toggle(testId `toggle-random-draft`). 꺼지면 팀 화면 랜덤 카드 숨김. 이적시장은 항상 표시.
- 교환: 스토어 `swapPlayer(teamId, outId, incoming)` 원자적. 들어온 선수는 나간 선수의 players 배열 위치·슬롯(positions 유지)·등번호를 물려받음. OVR 제한 없음(OVR 차이 표시). 내 팀 이름(normalizeName)은 후보에서 제외. 확인 대화상자 필수. 팀 화면에서만(경기 중 불가).
- `TransferMarket.tsx`: 내 선수 선택 → 시장 선수 선택 → 확인. 이름 검색, 리그 다중 필터, 포지션 필터, OVR 내림차순, 30개씩 더 보기. 데이터 면책 문구 표시.
- 리그 14개(기존 8 + 분데스리가, 에레디비시, 포르투갈, 튀르키예, 스코틀랜드, J리그, 아르헨티나), 약 640명. `data/leagues/*.ts`로 분리하고 이적시장 열 때 동적 import(서비스워커 오프라인 캐시 확인). 정규화 이름 전체 유일(테스트). OVR은 게임용 추정치.

## 4. 수용 기준
요구1: GK 슬롯 선수 필드 이동 시 에러/취소 · GK슬롯만 빈 상태 필드선수 드롭 에러(lineup 불변) · 선발 10명·교체 0에서 빈 슬롯 채우기 가능(subsUsed 불변) · 퇴장 에러 메시지 3초 표시 · 선택→벤치 탭 교체 · GK 퇴장 안내 · 기존 동작 불변 · 사진 팀: GK 없음→gk 비움, GK 2장→gk 1명, 3-4-3 사진→formationId "3-4-3" & shape 일치, "기본 위치로" 후 역할 일치(fit=1), 8명 선발 시 빈 슬롯이 빈 줄에.
요구2: 프리셋 4종 + 직접 입력 검증(합 10, 3~5개, 1~6)·사유 표시 · 새로고침 후 유지, 9번째 입력 시 가장 오래된 것 삭제 · 목록에서 지워도 팀 라인업 유지 · 기존 저장 데이터 불변 · 모르는 id는 4-4-2 · 퇴장 10명 팀에서도 선수 안 사라짐.
요구3: 25명에서 모든 추가 경로 차단+안내 · 남은 3명이면 11/16 비활성, 스캔 4번째 체크부터 차단 · 26명 팀 유지/표시/교환 가능 · 랜덤 on/off 유지(기본 true, 이전 저장 데이터 포함) · 이적시장 필터 조합 동작, 내 팀 이름 제외 · 교환 후 인원 불변, 슬롯·좌표·등번호 승계 · 경기 중 불가 · 이름 유일성 테스트.
