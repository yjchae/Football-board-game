# 🎲 게임 기획자 — 게임 기획서

## 1. 컨셉
> "내 카드 컬렉션이 진짜 팀이 된다!"

아이들이 모은 실물 축구 카드를 찍어 팀을 만들고, 감독이 되어 포메이션을 짜고 경기 중 교체를 결정한다. 경기는 AI 해설가가 실시간 중계처럼 보여준다.

**대상**: 초등학생 (보호자가 AI 키 설정) · **기기**: 태블릿 우선, PC·휴대폰 지원 · **인원**: 1~2명 (두 팀 모두 직접 조작 가능 → 형제/친구 대결)

## 2. 게임 흐름

```
[팀 만들기] → [카드 찍어 선수 등록] → [포지션 배치]
     ↓
[경기 준비: 홈/원정 선택] → [킥오프 전 마지막 정비]
     ↓
[전반 0~15'] → [15~30'] → [30~45']      ← 구간 사이 '작전 타임' 가능
     ↓
[하프타임: 전반 정리 · 하이라이트 · 교체/포메이션 변경]
     ↓  (▶ 후반 시작 버튼)
[후반 45~60'] → [60~75'] → [75~90']
     ↓
[경기 종료: 최종 결과 · 후반 정리 · 전/후반 하이라이트 · 전체 기록]
```

## 3. 규칙

| 항목 | 규칙 |
|---|---|
| 선발 | 최소 7명이 있어야 경기 시작 가능 (11명 권장) |
| 포메이션 | 4-4-2 / 4-3-3 / 3-5-2 / 4-2-3-1 |
| 교체 | 팀당 최대 **5회**, 교체되어 나간 선수는 재투입 불가 |
| 교체 시점 | 킥오프 전, 작전 타임(구간 사이), 하프타임 |
| 작전 타임 | 경기 중 버튼으로 요청 → 현재 15분 구간이 끝나면 멈춤 |
| 부상 | 부상 선수가 경기장에 남아 있으면 구간 종료 후 **자동 작전 타임** |
| 퇴장 | 레드카드 선수는 즉시 경기장에서 빠지고, 그 자리는 채울 수 없음 |
| 포지션 적합도 | 원래 역할과 다른 자리면 능력치 감소 (인접 역할 88%, 먼 역할 75%, GK↔필드 50%) |

## 4. 선수 데이터
카드에서 읽는 값: 이름, 등번호, 포지션 표기(ST/CAM/CB…), 종합능력치(OVR), 6개 세부 능력치(속도·슈팅·패스·드리블·수비·피지컬).
포지션 표기는 4개 역할(GK/DF/MF/FW)로 자동 분류한다.

카드 등급 표시: OVR 75+ 골드 / 65+ 실버 / 그 외 브론즈.

## 5. 경기 엔진 밸런스 (오프라인 엔진 기준)
- **중원 장악력**(MF 패스·드리블·피지컬) → 공격 기회 수
- **공격력**(FW 슈팅·속도·드리블) vs **수비력**(DF 수비·피지컬·속도 + GK OVR) → 골 확률
- 목표: 90분 평균 총 득점 약 2~4골 (단위 테스트로 1.5~5골 범위 확인)
- 의외성: 확률 기반이라 약팀도 이길 수 있음

AI 엔진에는 같은 정보(능력치·포지션·현재 점수·직전 장면)를 주고 "15분 구간 골은 보통 0~2개"라는 가이드를 준다.

## 6. 오프라인 엔진 해설 (`src/domain/commentary.ts`)
문장 틀 약 140개. 같은 경기 안에서 최근에 쓴 문장은 피해서 고른다.

| 구분 | 내용 |
|---|---|
| 득점 방식 6종 | 중거리 슛 · 드리블 돌파 · 역습 · 헤더 · 감아차기/칩슛 · 문전 마무리 — 득점자의 슈팅/드리블/속도/피지컬이 높을수록 그 방식이 자주 나옴 |
| 경기 상황 | 선제골 · 동점골 · 앞서가는 골 · 역전골 · 추가골 · 만회골 + 현재 점수 표시 |
| 기록 | 멀티골(2골), 해트트릭(3골) |
| 시간대 | 경기 초반(5분 이내) 골, 종료 직전(85분 이후) 극장골 |
| 그 외 | 도움 해설, 슈팅·선방 8종·빗나감 10종(골대 맞음/크로스바/수비 블록 등), 공격 전개, 코너킥, 오프사이드, 파울·경고·퇴장, 부상, 경기장 분위기 |
| 하프 정리 | 0:0 / 접전 / 대승 / 무승부 / 최종 승리 별 제목, 멀티골 선수·선방 많은 골키퍼·슈팅 많은 경기 언급 |

## 7. 하이라이트 기준
골, 결정적 선방, 퇴장 → 화면 전체 연출(GOAL! / SUPER SAVE! / RED CARD) + 하프 정리 화면의 하이라이트 카드 모음.

## 8. 아이 친화 원칙
- 해설은 쉬운 한국어, 신나는 말투, 폭력적 표현 금지 (AI 프롬프트에 명시)
- 실패해도 게임이 멈추지 않게 (AI 오류 → 오프라인 엔진 자동 대체)
- 큰 버튼, 이모지 아이콘, 탭 두 번으로도 선수 이동 가능
- 연습용 가상 팀 2개 제공 → 카드 없이도 바로 체험
