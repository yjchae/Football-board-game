# 🎨 UI 설계자 — 화면 설계서

## 1. 디자인 콘셉트: "야간 경기장 (Night Stadium)"
조명이 켜진 밤 경기장. 진한 잔디색 배경 위에 형광 라임 포인트, 선수 카드는 실제 트레이딩 카드처럼 금/은/동 메탈 질감.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#06140d` | 배경 (밤 잔디) |
| `--surface` | `#10291c` | 패널 |
| `--accent` | `#c6ff3d` | 주요 버튼, 점수, 강조 |
| `--danger` / `--warn` | `#ff5d73` / `#ffb547` | 경고, 오류 |
| 팀 색상 | 사용자 선택 | 팀 배지, 피드 테두리, 하이라이트 연출 |

**폰트**: 제목 `Black Han Sans`(굵고 경기장 전광판 느낌) · 본문 `IBM Plex Sans KR` · 숫자 `Chakra Petch`(스코어보드)

## 2. 화면 구조

```
┌ 상단바: 로고 | [팀 관리] [경기] [AI 설정] | 현재 엔진 ┐
│
├ 팀 관리
│   ├ 좌측: 팀 목록(팀 색 테두리) + 새 팀 만들기
│   └ 우측: 팀 헤더(이름 바로 수정) / 탭[선수 명단 | 포지션 배치]
│        ├ 선수 명단: '카드 찍어서 선수 등록' 타일 + 카드 그리드
│        └ 포지션 배치: 포메이션 선택 · 자동 배치 · 경기장 + 벤치
│
├ 경기
│   ├ 준비: HOME vs AWAY 선택 카드, 엔진 표시, 문제 안내, [경기 시작]
│   └ 진행: 고정 전광판(점수·시간·진행바)
│        ├ 킥오프 전: 교체 패널 + [킥오프!]
│        ├ 진행 중: [작전 타임 요청] + 실시간 중계 피드(최신이 위)
│        ├ 작전 타임: 교체 패널 + [경기 재개]
│        ├ 하프타임: 전반 정리 카드 → 전반 하이라이트 → 교체 패널 → [후반 시작]
│        └ 종료: 승리 배너 → 후반 정리 → 하이라이트 → 전반 정리 → 전체 기록
│
└ AI 설정: 엔진 카드 3개(제미나이/클로드/오프라인) · 키 입력 · 연결 테스트 · 중계 속도
```

## 3. 핵심 인터랙션

### 포지션 보드
- **드래그앤드롭**: 마우스/터치 모두 (터치는 120ms 누르면 집어짐 → 스크롤과 구분)
- **탭 두 번**: 선수 탭(흰 테두리 깜빡임) → 목적지 탭. 작은 손가락도 쉽게
- 원래 포지션이 아닌 자리 = **주황 테두리** (능력치 감소 알림)
- 경기 중: 교체아웃/퇴장 선수는 회색 처리, 부상 선수는 🚑 배지

### 선수 등록 (카드 촬영)
1. 큰 점선 사진 영역 → 휴대폰/태블릿에서는 바로 후면 카메라 실행
2. 찍으면 AI가 자동으로 카드 판독 → 폼 자동 채움 → "틀린 곳은 고쳐 주세요"
3. 슬라이더로 능력치 조정 (숫자 입력 대신 아이들이 쉽게)

### 하이라이트 연출
골/선방/퇴장 순간 화면 전체에 팀 색 방사형 빛 + 큰 글씨(GOAL!) + 선수 카드 사진 팝업 → 약 2초 후 자동 사라짐 (조작 방해 없음, `pointer-events: none`)

## 4. 반응형 기준
| 폭 | 레이아웃 |
|---|---|
| > 860px (PC) | 팀 목록 좌측 고정, 경기장 + 벤치 좌우 배치 |
| ≤ 860px (태블릿) | 팀 목록 가로 스크롤, 벤치는 경기장 아래 |
| ≤ 560px (휴대폰) | 상단바 2줄(고정 해제), 칩 축소, 폼 1열 |

## 5. 접근성
- `prefers-reduced-motion` 사용자: 애니메이션 최소화
- 버튼 최소 터치 영역 약 44px
- 색만으로 정보 전달 금지 (주황 테두리 + 안내 문구 병행)
