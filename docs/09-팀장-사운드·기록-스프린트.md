| 그 밖의 장면 | — | 중계 문장 (이모지 제거) |

- 설정에서 **효과음 / 음성 해설**을 각각 켜고 끌 수 있고, 경기 화면 🔊 버튼으로 둘 다 한 번에 끄고 켠다. 기본값은 둘 다 켜짐.

### 2-4. 경기 기록
- 경기가 **끝까지 끝났을 때만** 저장 (중간에 나간 경기는 저장 안 함).
- 저장 내용: 종료 시각, 두 팀 이름·엠블럼·색, 점수, 득점자(분·이름·팀). 팀을 나중에 지워도 기록은 그대로 보인다.
- **최근 10경기**만 유지 (최신이 맨 위). 같은 경기는 한 번만 저장. "기록 지우기"로 전부 삭제(확인창).

## 4. 💻 개발자 — 핵심 결정 (ADR)

### ADR-8. 소리는 음원 파일 없이 브라우저 기능으로
- **효과음**: Web Audio API로 합성 (휘슬 = 2750Hz 사인파 + 32Hz 떨림, 함성 = 대역 통과 잡음, 나팔 = 톱니파 4음). 저작권 걱정 없고, 앱 용량이 늘지 않으며 오프라인(PWA)에서도 동작.
- **음성 해설**: Web Speech API(`speechSynthesis`)의 한국어 목소리. 기기마다 목소리 품질이 다르다. [보통 확신 – 실기기 검증 권장]
- **자동재생 정책**: 브라우저는 사용자가 누른 순간에만 소리를 켤 수 있어 `킥오프`·`후반 시작` 버튼 클릭 안에서 `unlockSfx()`·`unlockNarration()`을 부른다.
- **이벤트 → 소리 규칙**은 순수 함수 `soundFor()`로 분리해 단위 테스트. 휘슬 판단은 문장이 아닌 이벤트의 `cue` 필드(`kickoff`/`second-half`/`halftime`/`fulltime`)로 한다.
- **해설과 속도 맞추기**: `useMatch`가 `isBusy()`를 받아, 낭독 중이면 200ms씩 미루며 최대 8초 기다린다.

### ADR-9. 경기 기록은 기존 저장소(IndexedDB)에 함께
- zustand `history` 필드로 팀·설정과 같은 저장소에 보관. 예전 저장 데이터에는 `history`가 없으므로 불러올 때 빈 배열로 채운다.

## 6. 후속 요청 — 실제 같은 휘슬·함성 (슈퍼 세이브 포함)

### 6-1. 팀장 결정
- 요청: 킥오프·전후반 종료에 **실제 휘슬 소리**, 골·**슈퍼 세이브**에 **함성**.
- 제약: 이 개발 환경은 패키지 저장소 외의 인터넷 접속이 막혀 있어 녹음 음원(예: 무료 효과음 사이트)을 내려받을 수 없었고, npm에서도 라이선스가 확인된 휘슬·관중 녹음은 찾지 못했다.
- 결정: **녹음과 비슷한 음질의 음원 파일을 물리 모델링으로 만들어 mp3로 넣고**, 나중에 실제 녹음 파일로 **같은 이름만 덮어쓰면** 그대로 쓰이게 구조를 바꾼다.

### 6-2. 기획 — 소리 규칙 변경
| 상황 | 이전 | 변경 |
|---|---|---|
| 킥오프·후반 시작 | 즉석 합성 휘슬 | `whistle-kickoff.mp3` (길게 1번) |
| 전반 종료 | 즉석 합성 휘슬 2번 | `whistle-halftime.mp3` (짧게·길게 2번) |
| 경기 종료 | 즉석 합성 휘슬 3번 | `whistle-fulltime.mp3` (짧게·짧게·길게 3번) |
| 골 | 잡음 함성 + 나팔 | `crowd-goal.mp3` (수백 명 "와아아!" + 박수 + 경기장 울림, 약 5초) |
| **슈퍼 세이브** | 없음 | `crowd-save.mp3` ("오오오!" 탄성 → 박수) + 해설 앞에 "슈퍼 세이브!" |

- 슈퍼 세이브 = 하이라이트로 뽑힌 선방(`type: 'save'`, `highlight: true`). 오프라인 엔진에서는 선방의 약 40%, AI 엔진은 "결정적 선방"으로 표시한 장면. 평범한 선방은 함성 없이 해설만.

### 6-3. 개발 — 음원 만들기 (`tools/make_sounds.py`, numpy + ffmpeg)
- **휘슬**: 약 3.4kHz 기음 + 배음, 구슬이 공기를 끊는 초당 28~38번의 불규칙한 떨림(주파수·음량 동시), 몸통 대역의 숨소리 잡음, 부는 세기에 따라 음높이가 살짝 오름, 짧은 잔향.
- **관중**: 어른·아이 음높이가 섞인 목소리 수백 개(시작 시각·크기·음높이 흔들림이 사람마다 다름)를 모음 "아/에"(골)·"오"(선방) 공명으로 걸러 군중처럼 만들고, 박수·멀리서 들리는 웅성거림·경기장 잔향을 섞었다.
- 품질 점검(스펙트로그램): 휘슬 3번 끊김과 떨림 확인, 함성의 0.15초 폭발→유지→감쇠 확인. 잔향 잡음이 특정 주파수를 키우는 문제와 저음을 칼같이 잘라 생긴 빈 줄을 발견해 수정.
- 재생: `src/assets/sounds/*.mp3`를 Vite가 해시 붙은 파일로 배포 → 킥오프 버튼을 누를 때 미리 받아 해독해 두고 재생. 파일을 못 받으면 예전 합성음으로 대체(경기가 조용해지지 않음). 서비스 워커가 한 번 받은 음원을 저장하므로 오프라인에서도 재생.
- 용량: 5개 합계 약 270KB.
