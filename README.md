# ⚽ 카드 풋볼 리그

실물 축구 카드를 사진으로 찍어 나만의 팀을 만들고, **제미나이 또는 클로드 AI**가 경기를 중계해 주는 아이들용 웹 보드게임입니다.

## 주요 기능
- 🏟️ **팀 만들기** — 이름·엠블럼·팀 색상
- 📸 **카드 찍어서 선수 등록** — AI가 카드의 이름·포지션·능력치를 읽어 자동 입력
- 🃏 **팀 한 번에 등록** — 카드 여러 장을 펼쳐 놓고 한 장으로 찍으면 모든 선수를 한꺼번에 등록 (사진 여러 장 가능, 카드별 사진 자동 잘라내기, 중복 이름 표시, 자동 포지션 배치)
- 📋 **포지션 배치** — 포메이션 4종에서 시작해 **빈 잔디 어디로든 자유롭게** 드래그 (서 있는 위치에 따라 수비·미드·공격 역할 자동 결정), 탭 두 번 이동, 자동 배치
- 📸 **사진 배치대로 포지션** — 카드를 포메이션 모양으로 놓고 찍으면 그 배치 그대로 선발이 섬 (어느 방향에서 찍어도 골키퍼 쪽을 우리 골문으로 인식)
- 🤖 **AI 경기 시뮬레이션** — 본인 제미나이/클로드 키 연결 (키가 없으면 오프라인 엔진)
- ⏱️ **전반 → 하프타임(정리·교체·포지션 정비) → 후반 시작 버튼 → 후반**
- 🔁 **경기 중 작전 타임**으로 선수 교체 (최대 5회), 부상 시 자동 작전 타임
- 🎬 **하이라이트** — 골/선방/퇴장 순간 연출 + 하프별 하이라이트 모음, 전반·후반 정리 카드
- 🔊 **사운드** — 실제 녹음 효과음 + 한국어 **음성 해설** (설정에서 켜고 끄기, 경기 중 🔊 버튼)
  - 휘슬: 킥오프·후반 시작(시작 휘슬) / 전반·경기 종료(종료 휘슬) / 파울·경고·퇴장·오프사이드(파울 휘슬)
  - 경기 소리: 골(슈팅음 + 큰 함성), 슈팅, 선방(짧은 함성), 돌파(드리블), 코너킥(킥) — 여러 녹음 중 무작위 재생
  - 음원은 `public/sfx/`에 있고, 불러오지 못하면 합성 휘슬·함성으로 대체
- 🐢 **중계 속도 5단계** — 아주 천천히(4.5초) ~ 빠르게(0.7초), 음성 해설이 끝날 때까지 기다림
- 🎲 **실존 선수 랜덤 뽑기** — 프리미어리그·라리가·세리에 A·리그 1·K리그·MLS·브라질·사우디 8개 리그
- 📜 **최근 경기 기록** — 끝난 경기의 점수·득점자를 최근 10경기까지 저장

## 바로 실행
```bash
npm install
npm run dev
```
브라우저에서 표시된 주소로 접속 → **팀 관리 → "연습용 팀 2개 불러오기"** → **경기**.

## 웹 배포 (GitHub Pages)
1. 저장소 **Settings → Pages → Source: GitHub Actions** 선택
2. `main` 브랜치에 병합하면 `.github/workflows/deploy.yml`이 테스트·빌드 후 자동 배포
3. `https://<계정>.github.io/<저장소>/` 로 아이들이 바로 접속

## 📲 홈 화면 앱으로 설치 (권장)
배포 주소에 접속한 뒤 기기에 앱처럼 설치하면, 아이콘을 눌러 전체 화면으로 바로 실행됩니다. 앱 파일이 기기에 저장되어 인터넷이 끊겨도 오프라인 엔진으로 경기할 수 있습니다.

| 기기 | 설치 방법 |
|---|---|
| 아이폰·아이패드 | **사파리**로 열기 → 공유 버튼 ⬆️ → **홈 화면에 추가** |
| 안드로이드 (크롬) | 화면 상단 안내의 **설치하기** 버튼, 또는 메뉴(⋮) → **앱 설치** |
| PC (크롬/엣지) | 주소창 오른쪽 설치 아이콘 |

> ⚠️ 아이폰·아이패드는 사파리와 홈 화면 앱의 저장 공간이 따로입니다. **설치한 앱을 연 뒤** AI 키 입력과 팀 등록을 해 주세요.

## AI 연결 (본인 계정)
- **제미나이**: Google AI Studio에 본인 구글 계정으로 로그인 → API 키 발급 → 앱의 **AI 설정**에 붙여넣기 → 연결 테스트
- **클로드**: Claude Console에서 API 키 발급 → **AI 설정**에 붙여넣기
- 키는 **설치한 그 기기에만 저장**됩니다. 같은 주소로 다른 사람이 접속해도 내 키는 쓰이지 않고, 그 기기로 게임하는 사람만 사용합니다. 키는 AI 회사 서버로만 직접 전송됩니다. 사용량에 따라 요금이 나올 수 있으니 보호자가 관리해 주세요.
